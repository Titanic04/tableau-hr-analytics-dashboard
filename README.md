# 📊 HR Analytics Dashboard – Tableau

## 📌 Project Overview

This project is an HR Analytics Dashboard created using Tableau.

The main objective of this dashboard is to transform HR data into meaningful visual insights related to employee demographics, salary, workforce growth, education qualification, and leave balance.

The dashboard is designed to answer important HR-related business questions and demonstrate how data visualization can support better understanding and decision-making.

---

## 🎯 Objectives

The key objectives of this project are:

- Analyze employee demographics
- Understand gender distribution
- Analyze employee age groups
- Identify top earners
- Study workforce growth over time
- Compare salary across education qualifications
- Analyze leave balance across different job roles
- Practice Tableau dashboard development
- Improve data visualization and storytelling skills

---

## 📊 Dashboard Insights

The dashboard focuses on the following questions:

### 👥 Who Works With Us?
Shows the distribution of employees across different job titles.

### 🚻 Gender Split
Visualizes the distribution of male and female employees.

### 🎂 Age Distribution
Shows the workforce distribution across different age groups.

### 💰 Who Gets Most Money?
Highlights employees with the highest salaries.

### 📈 How Did We Grow Over Time?
Shows workforce growth based on the year employees joined the organization.

### 🎓 Education vs Salary
Compares salary distribution across different education qualifications.

### 🏖️ Leave Balance Analysis
Shows leave balance across different job roles and genders.
